# Hyper Download Manager (HDM)
![HDMIcon](https://github.com/user-attachments/assets/58e0594b-11ba-4b80-8433-4a3b9469794d)

HDM is a sleek, high-performance download manager designed for speed, reliability, and ease of use. Featuring a modern, intuitive GUI, it simplifies managing downloads while maximizing efficiency with the power of dotnet and its powerful core.

# Key Features
1. Powerful core ensures your download never become corrupted
2. Containers which help you organize your downloads
3. Speed Plot for each download to monitor what exactly going on
4. Automatic pause and resume download in case of connection loss (can be disabled from Settings -> General Setting)
5. Scheduling your downloads to be run another time (or for simplicity schedule hole container for multiple downloads)

## Usage
1. Goto [release page](https://github.com/JxD8y/HyperDownloadManager/releases)
2. Download the latest release
3. Extract it and execute HyperDownloadManager.exe

# Build
Clone the repository and open it via visual studio click start and wait until all nuget packages are installed.
